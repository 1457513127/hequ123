# 校园安监应急小程序

基于 `uniapp + Vue3 + JavaScript` 的校园安监应急小程序前端工程。当前版本按 Axure 原型一期核心模块实现，采用 mock 数据优先，后续可替换为真实接口。

## 技术栈

- uniapp Vue3
- JavaScript
- 微信小程序目标端
- Vant 风格适配组件，自封装移动端基础组件

## 运行

```bash
npm install
npm run dev:h5
npm run build:mp-weixin
```

H5 预览地址：

```text
http://127.0.0.1:5173/
```

微信开发者工具导入目录：

```text
dist/build/mp-weixin
```

## 已实现范围

- 工作台：首页入口、用户信息、搜索、消息、宫格入口、通知公告、安全宣传、自定义底部导航。
- 待办：状态统计、任务类型切换、任务筛选、任务卡片。
- 安保对象：主页、建筑物/房间/风险点/重点人员列表与详情。
- 安保资源：主页、网格、物资库、物资、应急预案列表与详情。
- 隐患排查：检查计划、检查记录、复查记录、督办记录列表与详情。
- 安全随手拍：事件列表、详情、流转、办结、流转日志。
- 工作评价：绩效考核完成率。
- 安全教育：知识库、法规库、案例库。
